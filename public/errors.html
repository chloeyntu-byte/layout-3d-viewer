VL3D Error Index

Use browser Find for VL3D-E#### or E####. Direct links accept either anchor. Run node tools/vl3d.mjs doctor --json for machine-readable evidence.

VL3D-E1xxx - Dependencies

VL3D-E1001 (E1001) - Node.js is missing or unsupported ^

Severity
error
Cause
The launcher could not find a usable Node.js runtime at the supported baseline.
Fix
Install Node.js 18 or newer, or set `VL3D_NODE` to its executable path, then run `vl3d doctor` again.

VL3D-E1002 (E1002) - Python 3 was not found ^

Severity
warning
Cause
OA export, conversion, and stream import require Python 3; the static JSON viewer does not.
Fix
Install Python 3.6 or newer for OA/stream workflows, or set `VL3D_PYTHON`/`--python` to an executable path.

VL3D-E1003 (E1003) - No supported browser was found ^

Severity
warning
Cause
Neither Chromium nor Firefox was found in the configured path or PATH.
Fix
Install Chromium or Firefox, or select one with `--browser`.

VL3D-E1004 (E1004) - No graphical file picker was found ^

Severity
warning
Cause
Neither the built-in Tk picker nor a compatible Zenity/KDialog/YAD fallback is ready.
Fix
Repair the native Tk runtime, install one small picker package, or enter library paths manually in Advanced settings.

VL3D-E1005 (E1005) - xprop was not found ^

Severity
warning
Cause
The legacy external picker cannot attach itself to the active desktop window without xprop; the built-in Tk picker does not need it.
Fix
Use the built-in native picker, install the X11 utilities package containing xprop, or enter the path manually.

VL3D-E1006 (E1006) - KLayout compatibility fallback was not found ^

Severity
warning
Cause
The optional KLayout stream-import fallback is unavailable; the primary gdstk importer may still be ready.
Fix
Install the native runtime for gdstk, or install KLayout and set `KLAYOUT_BIN`/`--klayout`.

VL3D-E1007 (E1007) - KLayout compatibility fallback is not usable ^

Severity
warning
Cause
The optional KLayout executable failed its version probe or its runtime/plugins are incomplete.
Fix
Use the primary gdstk importer, or run `<klayout> -v` and repair the KLayout installation.

VL3D-E1008 (E1008) - Virtuoso was not found ^

Severity
warning
Cause
OA export requires a Virtuoso executable after the Cadence environment is loaded.
Fix
Select a Cadence environment adapter or set `VL3D_VIRTUOSO`/`--virtuoso`.

VL3D-E1009 (E1009) - Cadence license setting was not found ^

Severity
warning
Cause
Neither CDS_LIC_FILE nor LM_LICENSE_FILE is configured.
Fix
Load the site Cadence environment or provide `--license`; confirm the license server with your CAD administrator.

VL3D-E1010 (E1010) - Configured license file is unreadable ^

Severity
warning
Cause
The selected license value is a local file path that cannot be read.
Fix
Correct its path or permissions, or use the valid port@host license-server form.

VL3D-E1011 (E1011) - Display session was not detected ^

Severity
warning
Cause
On Linux, DISPLAY is absent, so Tk has no X11/XWayland display target.
Fix
Run in a desktop session, forward X11 correctly, enable XWayland when needed, or use non-GUI commands.

VL3D-E1012 (E1012) - System Tk is unavailable ^

Severity
error
Cause
The selected Python runtime cannot import Tkinter or cannot initialize Tk against the active display.
Fix
Install the operating-system Tk package matching Python, verify the display session, and rerun vl3d doctor.

VL3D-E1013 (E1013) - Native Python package setup failed ^

Severity
error
Cause
A required native-client Python package could not be detected or installed in the portable user environment.
Fix
Check the reported package, Python version, network or wheel compatibility, then rerun vl3d setup.

VL3D-E2xxx - Configuration and libraries

VL3D-E2001 (E2001) - Configuration JSON is invalid ^

Severity
error
Cause
A selected project or user configuration file cannot be parsed as JSON.
Fix
Validate the file with `python3 -m json.tool`, fix the reported syntax, and retry.

VL3D-E2002 (E2002) - Configuration root must be an object ^

Severity
error
Cause
The parsed configuration contains an array or scalar at its root.
Fix
Use a JSON object matching `vl3d.config.example.json`.

VL3D-E2003 (E2003) - cds.lib was not found ^

Severity
warning
Cause
No explicit, configured, environment, or nearby cds.lib/lib.defs candidate exists.
Fix
Use Load Library or pass `--cds-lib`; keep automatic discovery enabled for later runs.

VL3D-E2004 (E2004) - cds.lib is unreadable ^

Severity
error
Cause
The selected cds.lib/lib.defs path is not a readable regular file.
Fix
Correct the manual path and file permissions; do not replace it with a directory.

VL3D-E2005 (E2005) - No OA library was discovered ^

Severity
warning
Cause
The resolved cds.lib contains no readable DEFINE target with OA layouts.
Fix
Check INCLUDE variables, load the Cadence/PDK environment, or select the OA library directory manually.

VL3D-E2006 (E2006) - Library selection was cancelled ^

Severity
warning
Cause
The graphical picker closed without selecting a path.
Fix
Run Load Library again or type the library path manually.

VL3D-E2007 (E2007) - Selected library path is invalid ^

Severity
error
Cause
The manual library selection is missing, unreadable, or not a directory/cds.lib file.
Fix
Choose the OA library directory or its cds.lib/lib.defs file.

VL3D-E2008 (E2008) - Library discovery is ambiguous ^

Severity
warning
Cause
Multiple equally ranked library or configuration candidates were found.
Fix
Select the intended candidate manually; VL3D will not silently choose between equal candidates.

VL3D-E2009 (E2009) - Cadence environment adapter was not found ^

Severity
warning
Cause
No explicit, configured, or nearby environment adapter is available.
Fix
Select a site-provided adapter script in Advanced settings or set `VL3D_CADENCE_ENV`.

VL3D-E2010 (E2010) - cds.lib contains unresolved variables ^

Severity
warning
Cause
One or more INCLUDE/DEFINE paths depend on variables not present in the current process.
Fix
Select the Cadence environment adapter first, or replace the variable with a portable site configuration.

VL3D-E2011 (E2011) - Server port is invalid ^

Severity
error
Cause
The configured port is outside 1 through 65535 or is not an integer.
Fix
Choose a valid unprivileged port, for example 5177.

VL3D-E2012 (E2012) - Server port is already in use ^

Severity
error
Cause
Another process is listening on the requested host and port.
Fix
Stop the conflicting process or start VL3D with another `--port`.

VL3D-E2013 (E2013) - XDG directory is not writable ^

Severity
error
Cause
The configuration, cache, or state directory cannot be created or written safely.
Fix
Correct ownership/permissions or set the matching XDG environment variable to a writable location.

VL3D-E2014 (E2014) - Configuration write failed ^

Severity
error
Cause
The atomic setup write could not create, sync, or rename the user configuration.
Fix
Check free space and directory permissions, then rerun `vl3d setup --write`.

VL3D-E2015 (E2015) - Manual override is invalid ^

Severity
error
Cause
An explicit command-line or environment path was supplied but is unusable.
Fix
Correct or remove that explicit override; automatic detection never replaces it silently.

VL3D-E2016 (E2016) - Configuration schema is unsupported ^

Severity
error
Cause
The configuration schemaVersion is newer than this VL3D build understands.
Fix
Upgrade VL3D or migrate the configuration using the matching release notes.

VL3D-E2017 (E2017) - Library is absent from cds.lib ^

Severity
warning
Cause
The selected OA directory has no matching DEFINE entry.
Fix
Continue with the temporary library overlay, or add a site-approved DEFINE entry outside VL3D.

VL3D-E2018 (E2018) - No OA layout view was found ^

Severity
warning
Cause
The selected cell has no supported layout/maskLayout/chip/cLayout/dLayout/ivpcell view.
Fix
Enter a custom OA view in Advanced settings or confirm the layout was migrated.

VL3D-E2019 (E2019) - Graphical picker cannot be started ^

Severity
warning
Cause
A picker exists but the desktop launch failed.
Fix
Check DISPLAY/WAYLAND_DISPLAY and DBUS_SESSION_BUS_ADDRESS, then use manual entry if needed.

VL3D-E2020 (E2020) - Project root is invalid ^

Severity
error
Cause
The selected project root is missing, unreadable, or lacks tools/server.mjs.
Fix
Run VL3D from the installed project or pass its directory with `--root`.

VL3D-E2021 (E2021) - Project files are not readable ^

Severity
error
Cause
The server or public frontend cannot be read by the current account.
Fix
Correct project ownership/permissions or reinstall into a readable directory.

VL3D-E2022 (E2022) - Local API request was rejected ^

Severity
error
Cause
The request came from a non-loopback client, an untrusted origin, or an unsupported HTTP shape.
Fix
Open VL3D through its local server URL and do not proxy OA controls to untrusted clients.

VL3D-E2023 (E2023) - Library session expired ^

Severity
warning
Cause
The in-memory library token expired, was evicted, or belongs to an earlier server process.
Fix
Use Load Library again; saved paths remain available but session tokens are intentionally not persisted.

Severity
warning
Cause
The server was started without OA export enabled.

Restart with `vl3d start --enable-oa` after configuring Cadence safely.

VL3D-E3002 (E3002) - Cadence environment is unavailable ^

Severity
error
Cause
OA loading was requested without a readable Cadence environment adapter.
Fix
Select the adapter in Advanced settings or set `VL3D_CADENCE_ENV`.

VL3D-E3003 (E3003) - Virtuoso export process failed to launch ^

Severity
error
Cause
The sanitized OA export process could not execute Virtuoso.
Fix
Check the adapter, executable path, execute permissions, and supported OS libraries.

VL3D-E3004 (E3004) - OA database could not be opened ^

Severity
error
Cause
Virtuoso/OpenAccess rejected the selected library, cell, or view.
Fix
Open the same view in Virtuoso, inspect its log, and verify library/technology attachment.

VL3D-E3005 (E3005) - PCell evaluation failed ^

Severity
error
Cause
A PCell dependency, callback, or technology context failed during OA traversal.
Fix
Load the correct PDK initialization and verify the PCell in Virtuoso before retrying.

VL3D-E3006 (E3006) - OA master.tag is invalid ^

Severity
error
Cause
master.tag is malformed, unsafe, or points outside the selected view.
Fix
Repair the OA view through Virtuoso; do not hand-edit binary OA data.

VL3D-E3007 (E3007) - OA export timed out ^

Severity
error
Cause
Virtuoso traversal exceeded the configured export timeout.
Fix
Check for license dialogs or broken PCells, then reduce hierarchy/shape scope or raise the advanced timeout.

VL3D-E3008 (E3008) - Cadence license checkout failed ^

Severity
error
Cause
Virtuoso reported that a required license feature could not be checked out.
Fix
Verify license variables, server reachability, feature availability, and vendor daemon status.

VL3D-E3009 (E3009) - OA source changed during export ^

Severity
error
Cause
The selected OA view or configuration changed after discovery.
Fix
Close active edits, reload the library session, and export again.

VL3D-E3010 (E3010) - OA identity is invalid ^

Severity
error
Cause
Library, cell, or view names contain unsupported characters.
Fix
Select an OA-valid identity and avoid passing filesystem paths as cell names.

VL3D-E4xxx - Conversion

VL3D-E4001 (E4001) - Layout TSV schema is unsupported ^

Severity
error
Cause
The exporter and converter disagree on the intermediate schema version.
Fix
Use matching VL3D tools and regenerate the TSV instead of editing it manually.

VL3D-E4002 (E4002) - Layout TSV is malformed ^

Severity
error
Cause
A required record, field, number, or hierarchy reference cannot be parsed.
Fix
Inspect the export log, regenerate the source, and report the first rejected record.

VL3D-E4003 (E4003) - Layout units are invalid ^

Severity
error
Cause
The source database unit is invalid, or viewer JSON uses unsupported coordinate units.
Fix
Export normalized micrometer (um) geometry. Convert all coordinates and dimensions consistently; never just relabel the units field.

VL3D-E4004 (E4004) - Conversion resource limit was exceeded ^

Severity
error
Cause
Input size, shape count, hierarchy depth, or conversion time exceeded a safety limit.
Fix
Use advanced limits cautiously, flatten/select a smaller top cell, or run on a machine with more memory.

VL3D-E4005 (E4005) - Converted JSON could not be published ^

Severity
error
Cause
The converter could not atomically write the JSON or manifest entry.
Fix
Check cache permissions, free space, and stale lock files.

VL3D-E4006 (E4006) - Unsupported geometry was skipped ^

Severity
warning
Cause
The OA/stream source contains a shape type not represented by this viewer build.
Fix
Review the warning count and source layer; upgrade or add a minimal geometry handler if visually significant.

VL3D-E5xxx - PDK semantics

VL3D-E5001 (E5001) - Technology library was not identified ^

Severity
warning
Cause
No authoritative technology name was exported and no reliable fallback matched.
Fix
Select/create a PDK profile and confirm the technology attached to the OA library.

VL3D-E5002 (E5002) - PDK layer is unclassified ^

Severity
warning
Cause
A layer-purpose pair has no routing, via, device, pin, or auxiliary semantic.
Fix
Map it in a PDK profile; it remains preserved but hidden to avoid misleading geometry.

VL3D-E5003 (E5003) - Physical layer stack is incomplete ^

Severity
warning
Cause
One or more conductive layers lack trustworthy Z position or thickness.
Fix
Import the PDK stack/profile and confirm units; fallback spacing is visualization-only.

VL3D-E5004 (E5004) - Via endpoints are unknown ^

Severity
warning
Cause
A via could not be connected to unambiguous lower and upper routing layers.
Fix
Add via endpoint aliases to the PDK profile and verify its cut-layer purpose.

VL3D-E5005 (E5005) - PDK profile is invalid ^

Severity
error
Cause
The selected profile has an unsupported schema, duplicate mapping, or invalid numeric stack value.
Fix
Validate against the profile schema and correct the first reported field.

VL3D-E5006 (E5006) - Layer map conflicts with PDK metadata ^

Severity
warning
Cause
Stream mapping and profile semantics disagree for the same layer-purpose pair.
Fix
Prefer the foundry-approved map and explicitly override only the conflicting entry.

VL3D-E5007 (E5007) - PDK profile was inferred ^

Severity
warning
Cause
No authoritative technology identity was available, so a design-library or layer-signature matcher selected the profile.
Fix
Confirm the inferred profile and set an explicit profile override when physical Z accuracy matters.

VL3D-E5008 (E5008) - PDK profile source is unavailable ^

Severity
error
Cause
A configured profile file or directory is missing, unreadable, unsafe, oversized, or contains too many files.
Fix
Correct the profile path and permissions, or remove the invalid manual override.

VL3D-E5009 (E5009) - PDK profile selection is ambiguous ^

Severity
warning
Cause
More than one profile exactly matches the exported technology identity.
Fix
Remove duplicate aliases or explicitly select the intended profile; the highest-precedence match is temporary.

VL3D-E5010 (E5010) - Source technology layers conflict ^

Severity
warning
Cause
Multiple source technologies or contradictory OA materials share a layer identity.
Fix
Check source technology attachment. Conflicting material layers stay hidden; do not infer cross-technology connectivity.

VL3D-E6xxx - GDSII/OASIS stream

VL3D-E6001 (E6001) - Stream file cannot be read ^

Severity
error
Cause
The selected GDSII/OASIS path is missing, unreadable, or not a regular file.
Fix
Select a readable `.gds`, `.gdsii`, or `.oas` file.

VL3D-E6002 (E6002) - Stream top cell selection is required ^

Severity
error
Cause
The requested top cell is absent, or the stream contains multiple top cells and none was selected.
Fix
Choose one of the returned top-cell candidates and retry with that exact name.

VL3D-E6003 (E6003) - Stream layer map is invalid ^

Severity
error
Cause
The JSON layer map is malformed or contains invalid routing/defaultVisible types.
Fix
Start from the example map and correct the reported layer entry.

VL3D-E6004 (E6004) - Stream parser failed ^

Severity
error
Cause
gdstk and/or the configured KLayout fallback could not read or traverse the stream database.
Fix
Check file integrity and parser details; prefer a compatible gdstk wheel, or verify a complete KLayout installation.

VL3D-E6005 (E6005) - Stream import timed out ^

Severity
error
Cause
Stream parsing or hierarchy expansion exceeded the configured timeout.
Fix
Check file integrity, choose the correct top cell, reduce limits, or raise the advanced timeout on a capable machine.

VL3D-E6006 (E6006) - Stream has unmapped layers ^

Severity
warning
Cause
One or more layer/datatype pairs have no PDK mapping.
Fix
Load a foundry layer map; unknown layers are retained but hidden until explicitly mapped in Load setup.

VL3D-E6007 (E6007) - No usable stream parser is available ^

Severity
error
Cause
Neither a compatible gdstk installation nor a complete KLayout database reader is available.
Fix
Install the pinned gdstk wheel, or explicitly select a complete portable KLayout installation.

VL3D-E6008 (E6008) - Stream source changed during import ^

Severity
error
Cause
The selected JSON, GDSII, or OASIS file changed after validation and before cache publication.
Fix
Stop the writer, select the stable file again, and retry; no result from this attempt was published.

VL3D-E7xxx - Runtime cache

VL3D-E7001 (E7001) - Cache directory is unavailable ^

Severity
error
Cause
The runtime cache directory is missing, unsafe, or not writable.
Fix
Set XDG_CACHE_HOME/VL3D_CACHE_DIR to a writable local filesystem.

VL3D-E7002 (E7002) - Cache manifest is corrupt ^

Severity
error
Cause
manifest.json is invalid, oversized, or inconsistent with its entries.
Fix
Move the corrupt runtime cache aside and regenerate affected cells from source.

VL3D-E7003 (E7003) - Cached layout is stale ^

Severity
warning
Cause
OA source or converter fingerprints no longer match the cached entry.
Fix
Open the cell again to refresh it; do not reuse stale JSON for signoff.

VL3D-E7004 (E7004) - Cache lock could not be acquired ^

Severity
error
Cause
Another export holds the lock or a stale lock exceeded its timeout.
Fix
Wait for the active export; if none exists, inspect ownership before removing only the stale lock.

VL3D-E7005 (E7005) - Cache storage is full ^

Severity
error
Cause
The cache publish failed because the filesystem has insufficient free space or quota.
Fix
Use vl3d doctor to locate the data directory, move that entire directory aside, then reopen cells; or point VL3D_DATA_DIR at a filesystem with more free space. Do not delete individual cache files.

VL3D-E7006 (E7006) - Cache ownership is unsafe ^

Severity
error
Cause
Runtime files are owned by another account or are writable by untrusted users.
Fix
Correct ownership and use private XDG directories with 0700/0600 permissions.

VL3D-E8003 (E8003) - Frontend ran out of memory ^

error

VL3D-E8004 (E8004) - Interaction latency is excessive ^

Severity
warning

Frame time or fast-mode transition exceeds the interactive target.
Fix
Keep fast mode enabled, reduce edge/detail quality, and inspect the performance panel for the reported phase.

VL3D-E8005 (E8005) - Pointer controls behave unexpectedly ^

Severity
warning
Cause
Browser, touchpad, or configured orbit direction conflicts with expected gestures.
Fix
Reset controls, select the preferred orbit/pan direction, and verify with the interaction self-test.

VL3D-E8006 (E8006) - Layout data fetch failed ^

Severity
error
Cause
The browser could not fetch or decode the selected manifest/JSON resource.
Fix
Check the server response, cache entry, gzip sidecar, and browser network console.

VL3D-E8007 (E8007) - Canvas fallback limit was reached ^

Severity
warning
Cause
The non-WebGL renderer omitted detail to remain responsive.
Fix
Use WebGL or lower the visible hierarchy/layer count.

VL3D-E8008 (E8008) - Native Tk/OpenGL is unavailable ^

Severity
error
Cause
The native client cannot initialize Tk, the OpenGL widget, or the required GL capabilities.
Fix
Install the documented Tk/PyOpenGL packages, verify the display with glxinfo, then rerun vl3d doctor.

VL3D-E8009 (E8009) - Native backend connection failed ^

Severity
error

The private local backend failed to start, authenticate, or remain attached to its owning GUI process.

Restart VL3D, verify loopback access and the local control pipe, then inspect the backend startup diagnostic.
