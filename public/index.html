Layer map · Automatic

Maps stream layer numbers to conductors and explicit VIA endpoints. Supply a map when automatic recognition is incomplete; unsupported layers remain visible in Layers for inspection.

Pin annotations · optional for viewing

GDS/OAS geometry alone does not define pins. To trace a pin, select a sidecar created for this exact source, with explicit instance path, layer and geometry. Existing source geometry is preserved. First import once to inspect the exact source and hierarchy; create a sidecar from the inspection template, then import again with the sidecar. Pin annotation guide and examples.

PDK profile · Automatic mapping; inspect Layers

A viewer profile describing layer types and connector endpoints, not a PDK installation directory. Needed only when automatic mapping does not provide the required information. The loaded Layers and trace diagnostics show any remaining uncertainty.
